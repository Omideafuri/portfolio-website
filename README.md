## ✦ Typography Architecture — Helvetica × Reno Mono

The website employs a restrained, Swiss-inspired two-font system:

- **Primary Typeface (85–90%): Helvetica**
  - Minimal, precise, editorial, and confident.
  - Used for headlines, sublines, body copy, navigation, service descriptions, and primary CTA buttons.
  - Font stack: `"Helvetica Neue", Helvetica, "Segoe UI", Arial, -apple-system, sans-serif`.
- **Secondary Typeface (10–15%): Reno Mono**
  - Technical annotation layer.
  - Used for section indexes (`01 / WORK`), project numbers, technology stacks (`NEXT.JS · REACT · TYPESCRIPT`), dates, metadata tags, and microcopy.
  - Font stack: `"Reno Mono", "JetBrains Mono", "SF Mono", "Fira Code", monospace`.
